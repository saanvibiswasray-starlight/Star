# Star

A collection of simple Python games and mini-projects.

## Included Games

### 1. Rock Paper Scissors
A command-line game where the player competes against the computer.

Run:

```bash
python3 rock_paper_scissors.py
```

Controls:
- `R` for Rock
- `P` for Paper
- `S` for Scissors
- `Q` to quit

Rules:
- Rock beats Scissors
- Paper beats Rock
- Scissors beats Paper
- Same choice results in a draw

### 2. Number Guessing Game
A simple number guessing game where the user tries to guess a random number between 0 and 6.

Run:

```bash
python3 number_guessing_game.py
```

## Requirements

- Python 3

## Notes

This repository is intended for learning and practicing Python programming through small interactive games.
